BASIX — The Number Base Lab

Files:
- index.html
- style.css
- script.js

How to run:
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open index.html in a browser, or use the Live Server extension.
4. Click START GAME.

Features:
- Decimal, Binary, Octal and Hexadecimal conversion
- 12 conversion directions through the Number Lab
- Step-by-step X-Ray explanation
- Conversion Radar
- 5-level escape-room game
- Binary Lab
- Conversion Tunnel
- Four-Way Converter
- Glitch Hunt
- Memory Match
- Score, lives, hints and accuracy
- Responsive UI

Technology:
HTML + CSS + JavaScript only.
